# Zgłoszenia — Jawne Państwo

To repozytorium służy do zgłaszania błędów i propozycji dotyczących serwisu
[jawnepanstwo.pl](https://jawnepanstwo.pl), który pokazuje pracę Sejmu, Senatu
i administracji na podstawie danych publicznych.

Kod serwisu nie jest tu publikowany. Tu trafiają zgłoszenia od czytelników.

## Co można zgłosić

- **Błąd w danych** — liczba, data, nazwisko albo status ustawy niezgodne ze źródłem
  (Sejm, Senat, ISAP, RCL, EUR-Lex, Trybunał Konstytucyjny, Ministerstwo Finansów).
- **Błąd strony** — coś się nie wyświetla, link prowadzi donikąd, filtr nie działa.
- **Propozycja** — brakujące dane, nowa funkcja albo zmiana sposobu prezentacji.

Wybierz odpowiedni szablon po kliknięciu „New issue”. Im dokładniej opiszesz,
gdzie widać problem (adres strony) i jak powinno być według źródła (link), tym
szybciej da się go sprawdzić.

## Zanim zgłosisz

Zgłoszenia są publiczne. Nie podawaj w nich danych osobowych osób prywatnych.
Prośby o usunięcie danych osobowych z serwisu kieruj przez stronę
[jawnepanstwo.pl/prywatnosc](https://jawnepanstwo.pl/prywatnosc).

Nie masz konta na GitHubie? Napisz na kontakt@jawnepanstwo.pl.
